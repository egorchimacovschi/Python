# pygame

Game-development practice with pygame — separate from the PyQt5/general-Python practice in the sibling [`PyQt5`](../PyQt5) folder.

## 📁 What's Inside

| Folder | Content |
|---|---|
| [`pygame_example_tutorial`](./pygame_example_tutorial) | A tile-based 2D platformer (window title "Ninja-Game"), built by following a pygame tutorial — tilemap rendering, a physics entity with gravity and tile collision, and a large set of animation/tile/sound assets |
| `.vscode/` | Editor-only settings for this folder (interpreter selection); not part of the game itself |

See [`pygame_example_tutorial`](./pygame_example_tutorial)'s own README for a full breakdown of the code/assets and how to run it.

Note: the earlier from-scratch Flappy Bird build-along (window resizing, fullscreen, gravity/flap, ground collision) that came before this platformer tutorial grew into its own project — see [`AI_FLAPPY_BIRDS`](../../Projects/AI_FLAPPY_BIRDS) under `Projects/`.
